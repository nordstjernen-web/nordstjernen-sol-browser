# Nordstjernen documentation

Index of the docs in this directory. The project overview is in the
top-level [README.md](../README.md); the development plan is
[NORDSTJERNEN.md](../NORDSTJERNEN.md); the AI working rules are in
[CLAUDE.md](../CLAUDE.md) (Claude) and [AGENTS.md](../AGENTS.md) (Codex).
Release notes are in [Changelog.md](../Changelog.md), vulnerability
reporting in [SECURITY.md](../SECURITY.md), the threat model and defences in
[security-model.md](security-model.md), and licensing in
[License.md](../License.md) and
[THIRD-PARTY-LICENSES.md](../THIRD-PARTY-LICENSES.md).

## Using the browser

- [Controls.md](Controls.md) — keyboard, mouse, and touch controls.

- [privacy-policy.md](privacy-policy.md) — what the browser does and does not collect.

- [webdriver.md](webdriver.md) — drive the browser from Selenium, WebdriverIO and other WebDriver clients (`nordstjernen --webdriver`).
